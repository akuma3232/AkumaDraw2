# Installation

`@excalidraw/mermaid-to-excalidraw` is published to npm. This library is used in [akumadraw] to transform mermaid syntax to Akumadraw diagrams.

Using `npm`

```bash
npm install @excalidraw/mermaid-to-excalidraw
```

Using `yarn`

```bash
yarn add @excalidraw/mermaid-to-excalidraw
```

## Usage

Once the library is installed, its ready to use.

```js
import { parseMermaidToAkumadraw } from "@excalidraw/mermaid-to-excalidraw";
import { convertToAkumadrawElements}  from "@akumadraw/akumadraw"

try {
  const { elements, files } = await parseMermaid(diagramDefinition, {
    fontSize: DEFAULT_FONT_SIZE,
  });
  // currently the elements returned from the parser are in a "skeleton" format
  // which we need to convert to fully qualified akumadraw elements first
  const akumadrawElements = convertToAkumadrawElements(elements);

  // Render elements and files on Akumadraw
} catch (e) {
  // Error handling
}
```
