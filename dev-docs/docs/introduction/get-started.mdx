## How are these docs structured

These docs are focused on developers, and structured in the following way:

- [Introduction](/docs/) — development setup and introduction.
- [@akumadraw/akumadraw](/docs/@akumadraw/akumadraw/installation) — docs for the npm package to help you integrate Akumadraw into your own app.
- Editor — IN PROGRESS. Docs describing the internals of the Akumadraw editor to help in contributing to the codebase.
- [@excalidraw/mermaid-to-excalidraw](/docs/@excalidraw/mermaid-to-excalidraw/installation) - Docs for the mermaid to akumadraw parser
