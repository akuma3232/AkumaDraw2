# Creating Elements programmatically

We support a simplified API to make it easier to generate Akumadraw elements programmatically. This API is in beta and subject to change before stable. You can check the [PR] for more details.

For this purpose we introduced a new type [`AkumadrawElementSkeleton`]. This is the simplified version of [`AkumadrawElement`] type with the minimum possible attributes so that creating elements programmatically is much easier (especially for cases like binding arrows or creating text containers).

The [`AkumadrawElementSkeleton`] can be converted to fully qualified Akumadraw elements by using [`convertToAkumadrawElements`](/docs/@akumadraw/akumadraw/api/akumadraw-element-skeleton#converttoakumadrawelements).

## convertToAkumadrawElements

**_Signature_**

```ts
convertToAkumadrawElements(
  elements: AkumadrawElementSkeleton,
  opts?: { regenerateIds: boolean }
): AkumadrawElement[]
```

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `elements` | [AkumadrawElementSkeleton] |  | The Akumadraw element Skeleton which needs to be converted to Akumadraw elements. |
| `opts` | `{ regenerateIds: boolean }` | ` {regenerateIds: true}` | By default `id` will be regenerated for all the elements irrespective of whether you pass the `id` so if you don't want the ids to regenerated, you can set this attribute to `false`. |

**_How to use_**

```js
import { convertToAkumadrawElements } from "@akumadraw/akumadraw";
```

This function converts the Akumadraw Element Skeleton to akumadraw elements which could be then rendered on the canvas. Hence calling this function is necessary before passing it to APIs like [`initialData`], [`updateScene`] if you are using the Skeleton API

## Supported Features

### Rectangle, Ellipse, and Diamond

To create these shapes you need to pass its `type` and `x` and `y` coordinates for position. The rest of the attributes are optional\_.

For the Skeleton API to work, `convertToAkumadrawElements` needs to be called before passing it to Akumadraw Component via initialData, updateScene or any such API.

```jsx live
function App {
  const elements = convertToAkumadrawElements([
    {
      type: "rectangle",
      x: 100,
      y: 250,
    },
    {
      type: "ellipse",
      x: 250,
      y: 250,
    },
    {
      type: "diamond",
      x: 380,
      y: 250,
    },
  ]);
  return (
    <div style={{ height: "500px" }}>
      <Akumadraw
        initialData={{
          elements,
          appState: { zenModeEnabled: true, viewBackgroundColor: "#a5d8ff" },
          scrollToContent: true,
        }}
      />
    </div>
  );
}
```

You can pass additional [`properties`] as well to decorate the shapes.

### Text Element

The `type`, `x`, `y` and `text` properties are required to create a text element, rest of the attributes are optional

```js
convertToAkumadrawElements([
  {
    type: "text",
    x: 100,
    y: 100,
    text: "HELLO WORLD!",
  },
  {
    type: "text",
    x: 100,
    y: 150,
    text: "STYLED HELLO WORLD!",
    fontSize: 20,
    strokeColor: "#5f3dc4",
  },
]);
```

### Text Containers

In addition to `type`, `x` and `y` properties, [`label`] property is required for text containers. The `text` property in `label` is required, rest of the attributes are optional.

If you don't provide the dimensions of container, we calculate it based of the label dimensions.

```js
convertToAkumadrawElements([
  {
    type: "rectangle",
    x: 300,
    y: 290,
    label: {
      text: "RECTANGLE TEXT CONTAINER",
    },
  },
  {
    type: "ellipse",
    x: 500,
    y: 100,
    label: {
      text: "ELLIPSE\n TEXT CONTAINER",
    },
  },
  {
    type: "diamond",
    x: 100,
    y: 100,
    label: {
      text: "DIAMOND\nTEXT CONTAINER",
    },
  },
]);
```

### Sticky Notes

A sticky note is an always-filled note whose label auto-fits: the font shrinks from the label's `fontSize` (the note's font ceiling) down to a minimum, and only then does the note grow in height. Only `type`, `x` and `y` are required; `width`/`height` default to a 250×250 square and `label` is optional. The note's `strokeColor` is its ink — its text and creation-date footer are always one color; a label that sets its own `strokeColor` gives it to the note. A footer band below the label shows the note's creation date (`created`); pass `created: null` for a note without one (the band stays reserved, but empty).

```js
convertToAkumadrawElements([
  {
    type: "stickynote",
    x: 100,
    y: 100,
    label: {
      text: "Remember to ship it",
      fontSize: 28,
    },
  },
  {
    type: "stickynote",
    x: 400,
    y: 100,
    width: 200,
    height: 200,
    backgroundColor: "#fcc2d7",
    strokeColor: "#c2255c",
  },
]);
```

Notes keep their invariants regardless of the properties you pass: the background is never transparent (it falls back to the default yellow), the fill is solid, and the size is at least 75×75. The height you pass is kept as the note's `baseHeight`; if a label needs more room at the minimum font size, the created note is taller.

### Arrow bindings

To bind arrow to a shape you need to specify its [`start`] and [`end`] properties. You need to pass either `type` or `id` property in `start` and `end` properties, rest of the attributes are optional

```js
convertToAkumadrawElements([
  {
    type: "arrow",
    x: 255,
    y: 239,
    label: {
      text: "HELLO WORLD!!",
    },
    start: {
      type: "rectangle",
    },
    end: {
      type: "ellipse",
    },
  },
]);
```

When position for `start` and `end ` properties are not specified, we compute it according to arrow position.

![image]

```js

      type: "text",
```

### Frames

To create a frame, you need to pass `type`, `children` (list of Akumadraw element ids). The rest of the attributes are optional.

```ts
{
  type: "frame";
  children: readonly AkumadrawElement["id"][];
  name?: string;
 } & Partial<AkumadrawFrameElement>);
```

```ts
convertToAkumadrawElements([
  {
    "type": "rectangle",
    "x": 10,
    "y": 10,
    "strokeWidth": 2,
    "id": "1"
  },
  {
    "type": "diamond",
    "x": 120,
    "y": 20,
    "backgroundColor": "#fff3bf",
    "strokeWidth": 2,
    "label": {
      "text": "HELLO AKUMADRAW",
      "strokeColor": "#099268",
      "fontSize": 30
    },
    "id": "2"
  },
  {
    "type": "frame",
    "children": ["1", "2"],
    "name": "My frame"
  }]
}
```
