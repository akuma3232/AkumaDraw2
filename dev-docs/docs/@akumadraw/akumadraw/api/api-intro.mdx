# API

Currently the **API** is divided into 3 broad categories 👇

- [Props](/docs/@akumadraw/akumadraw/api/props) - The `props` you can pass to the `Akumadraw` component.
- [Children components](/docs/@akumadraw/akumadraw/api/children-components) - Official components you can use to customize the UI.
- [Utils](/docs/@akumadraw/akumadraw/api/utils) - Utilities and helpers you can use to export, restore and more.
