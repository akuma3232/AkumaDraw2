# Installation

**Akumadraw** is exported as a component to be directly embedded in your project.

Use `npm` or `yarn` to install the package.

```bash
npm install react react-dom @akumadraw/akumadraw
# or
yarn add react react-dom @akumadraw/akumadraw
```

:::tip

**If you don't want to wait for the next stable release and try out the unreleased changes you can use `@akumadraw/akumadraw@next`.**

:::

### Self-hosting fonts

By default, Akumadraw will try to download all the used fonts from the CDN.

For self-hosting purposes, you'll have to copy the content of the folder `node_modules/@akumadraw/akumadraw/dist/prod/fonts` to the path where your assets should be served from (i.e. `public/` directory in your project). In that case, you should also set `window.AKUMADRAW_ASSET_PATH` to the very same path, i.e. `/` in case it's in the root:

```js
window.AKUMADRAW_ASSET_PATH = "/";
```

or, if you serve your assets from the root of your CDN, you would do:

```js
// Vanilla
<head>
    <script>
        window.AKUMADRAW_ASSET_PATH = "";
    </script>    
</head>
```

or, if you prefer the path to be dynamicly set based on the `location.origin`, you could do the following:

```jsx
// Next.js
<Script id="load-env-variables" strategy="beforeInteractive" >
    { `window["AKUMADRAW_ASSET_PATH"] = location.origin;` } // or use just "/"!
</Script>
```

### Dimensions of Akumadraw

Akumadraw takes _100%_ of `width` and `height` of the containing block so make sure the container in which you render Akumadraw has non zero dimensions.
